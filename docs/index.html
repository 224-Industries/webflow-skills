What are Agent Skills?

An agent skill is a folder containing instructions, reference docs, and scripts that an AI agent can read when it needs them. Think of it like an onboarding guide you'd hand a new team member on their first day, except the new hire is an AI model.

Each skill has a SKILL.md file that tells the agent what the skill does and when to use it. When the agent encounters a task that matches, it reads the instructions and gets to work with the right context. No guessing, no hallucinating, no generic output.

Anthropic originally built skills for Claude, then released the format as an open standard. Now they work across a growing number of AI tools, and partners like Canva, Notion, Figma, and Atlassian are already building their own.

webflow / Browser API

Lets your agent handle cookie consent, A/B test tracking and personalisation on a Webflow site that runs Analyze or Optimize, using Webflow's own browser code rather than guesswork.

What it helps with

  • Connecting your consent banner, such as CookieYes, so Webflow only tracks visitors who said yes.
  • Sending Optimize test results into the analytics tool your team already reports from.
  • Tagging visitors with your own attributes, such as plan or industry, so tests and personalisation can target them.

What you'll need

A Webflow site with Analyze or Optimize turned on. Custom visitor attributes need an Enterprise site. No MCP server.

Good to know

The skill writes the script. Someone still adds it to the site's head code and publishes, and it doesn't set up Analyze or Optimize for you.

webflow / Code Components

For when a page needs something Webflow can't build natively, like a pricing calculator or an interactive demo. Your agent builds it in React and brings it into Webflow as a component your team places like any other element.

What it helps with

  • Building the React component and the settings your team edits in the Designer: text, images, links, toggles and more.
  • Packaging the component and importing it into Webflow through DevLink.
  • Fixing the usual problems with styling, shared state and imports.

What you'll need

A developer setup with Node.js 20 or later, and a Webflow Workspace on Freelancer, Core, Growth, Agency or Enterprise (or a site on CMS, Business or Enterprise). No MCP server.

Good to know

This is a developer skill. Renaming a component file creates a new component and breaks the copies already on your pages, so it pays to settle names early.

webflow / Designer API

Helps your agent build tools that work inside the Webflow Designer, from a short script that makes a batch of changes in one go to a full app your team installs.

What it helps with

  • Running one-off automations in the Designer API Playground, without building an app.
  • Building a Designer Extension: a tool with its own panel inside the Designer, for jobs your team repeats.
  • Creating and editing elements, styles, components, pages, variables and assets through code.
  • Designing an extension that looks native to Webflow and preparing it for Marketplace review.

What you'll need

Designer access to the site, plus the Webflow CLI if you're building an extension. No MCP server.

Good to know

Designer API code runs inside the Designer while it's open, so it suits build work rather than anything that has to run on the live site. Changes still need publishing.

webflow / Enterprise API

For teams on Webflow Enterprise who manage several sites or need a record of who changed what. Your agent works with the endpoints only Enterprise workspaces get.

What it helps with

  • Reading workspace audit logs (logins, role changes, invitations) and site activity logs (design changes, publishes, CMS edits).
  • Managing 301 redirects in bulk, for example during a migration or a URL restructure.
  • Updating robots.txt and uploading .well-known files without opening Site settings.
  • Creating, updating and deleting sites in a workspace.

What you'll need

An Enterprise workspace and an API token with the right permissions. No MCP server.

Good to know

On other plans these endpoints return errors. Redirect and robots.txt changes affect search directly, so review the list before your agent writes it.

webflow / Insights

Ask how your site is going in plain English and get an answer from Webflow's own data: traffic, top pages, whether a test has a winner, and what AI crawlers are reading.

What it helps with

  • A snapshot of the last 28 days with no question needed, plus suggestions for what to ask next.
  • A monthly check-up that compares last month with the one before.
  • Working out why traffic changed, with a confidence level on the answer.
  • Reading A/B test results without calling a winner too early.

What you'll need

Webflow's MCP server connected to your AI agent, and access to whichever of Analyze, Optimize and AEO Analytics the site has.

Good to know

It's read-only, so it can't change your site. A visit from an AI crawler isn't the same as being cited in an AI answer, and the skill keeps the two apart. AEO Analytics is mostly found on enterprise plans.

webflow / llms.txt

llms.txt is a plain-text map that helps AI tools understand what's on your site. Webflow doesn't update it for you, so it drifts as pages change. This skill rebuilds it from your site as it is today.

What it helps with

  • Producing a fresh llms.txt, with descriptions written from what each page actually says.
  • Writing the overview block that describes your business in your own words.
  • Listing what changed since the last run: new pages, removed pages and changed URLs.
  • Checking the links in the file before you upload it.

What you'll need

Your live site. A Webflow API token or the MCP server gives a more accurate page list; without one, the skill works from your sitemap.

Good to know

It doesn't publish anything. A person uploads the file in Site settings > SEO > LLMs.txt. Pages with no readable content are left out rather than given a made-up description.

webflow / Schema

Schema (JSON-LD) is the structured data that helps Google and AI tools understand a page, and it's what makes FAQ and article rich results possible. This skill builds it on Webflow and works around two platform limits that quietly break it.

What it helps with

  • Adding schema to CMS templates, so each blog post or case study gets its own, filled from your CMS fields.
  • Auditing the schema a live page actually ships, and explaining Search Console warnings.
  • Cleaning up Webflow's auto-generated schema and fixing wrong published dates.

What you'll need

To audit, a live URL. To write schema, Webflow's MCP server or an API token.

Good to know

Webflow escapes apostrophes, quotes and ampersands in CMS values bound to schema, and rich text fields come through empty. The skill checks your content for both. Changes are staged unpublished for a person to publish.

webflow / Webhooks

Webhooks let Webflow tell your other tools when something happens, like a form submission, a new order or a published CMS item. This skill helps your agent build the receiving end securely.

What it helps with

  • Handling Webflow's 14 event types across forms, site publishes, pages, ecommerce, CMS and comments.
  • Checking that each request really came from Webflow, so a faked one gets rejected.
  • Handling retries, so a slow response doesn't create duplicate records.

What you'll need

A server or serverless function to receive events. To verify requests, create the webhooks through the API rather than the dashboard. No MCP server.

Good to know

Webhooks created in the Webflow dashboard don't carry the signature needed to verify them. This is a developer skill: it writes the handler code, and someone deploys it.

What teams use these skills for

Three workflows we see most, from our client work and the community.

Shipping React components without the handover friction. A marketing site that needs a custom calculator or an interactive demo usually means a developer handover and a wait. With the Code Components skill, your agent scaffolds the React component, writes the declareComponent definition, and imports it through DevLink so your team can place it like any other element.

Running consent and experiments without hand-rolled scripts. The Browser API skill gives your agent working knowledge of Webflow Analyze & Optimize: wiring up a consent management platform, tracking experiments, and personalizing experiences without guessing at API calls.

Automating publish workflows end to end. Pair the skills with Webflow's official MCP server and your agent can write to the CMS directly. The Webhooks skill then covers what happens next: verified handlers for form submissions, publish events, and collection changes that trigger follow-up work like cache purges or Slack notifications.

For how this fits into a wider AI workflow, see our guides on Webflow AI in 2026 and automating Webflow with AI.

Installation

Add the skills to your favorite AI agents and platforms in just a few clicks.

# Add the plugin (includes all skills) /plugin add 224-industries/webflow-skills Also supported in Factory's Droid.
# 1. Download the .skill file from the skills above # 2. Go to Customize > Skills in Claude # 3. Click "+" then "Upload a skill" # 4. Upload the .skill file and toggle it on Skills are also supported in Claude Desktop and Claude Cowork.

Frequently Asked Questions

What are Agent Skills?

An agent skill is a folder containing instructions, reference docs, and scripts that an AI agent can read when it needs them. Each skill has a SKILL.md file that tells the agent what the skill does and when to use it. When the agent encounters a matching task, it reads the instructions and works with the right context. No guessing, no hallucinating, no generic output.

Which AI tools support Agent Skills?

Agent Skills work across Claude Web, Claude Desktop, Claude Cowork, Claude Code, Gumloop, the Vercel AI SDK, Playbooks, and Context7. Any AI agent that supports the open Agent Skills standard can use them. Anthropic originally built the format for Claude, then released it as an open standard.

What Webflow skills are available?

There are eight open-source skills: webflow-browser-api for tracking and consent management, webflow-code-components for React components via DevLink, webflow-designer-api for Designer Extensions and the Playground, webflow-enterprise-api for enterprise-only endpoints, webflow-insights for reading Analyze, Optimize and AEO Analytics data, webflow-llms-txt for generating and maintaining an llms.txt file, webflow-schema for building and auditing JSON-LD structured data, and webflow-webhooks for receiving and verifying webhook events.

How do I install Webflow Agent Skills?

The fastest way is to download a .skill file and upload it in Claude via Customize > Skills. You can also install via the Skills CLI (npx skills add 224-industries/webflow-skills), Claude Code (/plugin add 224-industries/webflow-skills), Gumloop, Playbooks, or Context7. See the installation section above for full instructions.

What is the difference between Agent Skills and MCP?

MCP gives an agent access: a live connection to Webflow's APIs so it can read and change your site. Agent Skills give it knowledge: packaged instructions for doing a job well. They work best together. An agent with Webflow's MCP server but no skills has the keys without the map.

Do I need the Webflow MCP server to use these skills?

Not for all of them. The code-components and designer-api skills guide local builds, and the webhooks skill covers handlers on your own server. The llms.txt skill can work from your sitemap, and the schema skill can audit any live page without a connection. For CMS writes, schema writes and site management, connect Webflow's official MCP server alongside the skills.

Can I create my own Agent Skills?

Yes. A skill is just a folder with a SKILL.md file and any supporting references, scripts, or assets. Create a SKILL.md with YAML frontmatter (name and description), add your instructions in the body, and you have a working skill. See the Agent Skills specification for the full format.

Are these skills free to use?

Yes. All eight Webflow skills in this repository are open-source under the MIT license. You can use, modify, and distribute them freely. Premium skills covering strategy, discovery, and client workflows are available separately in the Webflow Skills Kit.
